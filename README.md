# 🀄 電脳麻雀卓 (4人対戦型麻雀Webゲーム)

ブラウザ上で軽快に動作する、美麗で本格的な4人対戦型麻雀Webゲームです。

## ✨ 特徴

- **1人プレイモード (CPU対戦)**:
  - 思考AIエンジン（シャンテン数・有効牌・役考慮）を搭載した3体のCPU（風神・雷神・雀鬼）と即座に対戦できます。
- **オンライン4人対戦 (ルーム合言葉制)**:
  - WebRTC (PeerJS) によるリアルタイム通信。サーバー契約不要・完全無料。
  - 部屋番号（合言葉）を友達に教えるだけで簡単マッチング。
  - 人数が4人揃わない場合も、不足枠はCPUが自動で補填して即開始可能！
- **リアルタイムチャット & クイック定型文スタンプ**:
  - フリーテキストチャットに加え、「よろしくお願いします！」「ナイス！」「悔しい〜！」「ロン！」「リーチ！」などのクイック定型文をワンクリック送信。
  - 卓上のプレイヤーアバター横にアニメーション吹き出しで表示されます。
- **本格的な日本標準アリアルール (東風戦)**:
  - 25,000点持ち / 30,000点返し
  - 喰いタンあり / 後付けあり
  - 赤ドラ3枚（赤5萬・赤5筒・赤5索）
  - リーチ・一発・裏ドラ・カンドラ
  - 鳴き（ポン・チー・カン）
  - 符計算・翻計算・満貫〜役満判定・点数授受
  - 荒牌流局・ノーテン罰符精算・連荘/輪荘処理
- **Web Audio API による高品位な効果音**:
  - 心地よい打牌音、ツモ音、鳴きアクセント、リーチ宣言音、アガリファンファーレ

## 🛠 技術スタック

- **フロントエンド**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide React
- **リアルタイム通信**: PeerJS (WebRTC P2P)
- **演出**: Canvas Confetti, Web Audio API
- **テスト**: Vitest

## 🚀 起動方法

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# テスト実行
npm test

# プロダクションビルド
npm run build
```
